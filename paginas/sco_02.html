02 O QUE É SISTEMA OPERACIONAL?
O "maestro" do computador
O Sistema Operacional (SO) é o software principal que gerencia todos os recursos do computador. Ele controla o hardware, executa os programas e cria a interface que usamos para interagir com a máquina.
💡 Funções principais
• Gerencia o hardware (processador, memória, disco)
• Executa e organiza os programas
• Controla arquivos e pastas
• Oferece a interface gráfica (ícones, janelas, menus)
📝 Analogia: O SO é como o gerente de uma empresa — ele coordena os funcionários (programas) e os recursos (hardware) para que tudo funcione em harmonia.

06 PASTAS E ARQUIVOS
📁 Pastas
São contêineres que organizam arquivos. Funcionam como gavetas em um armário — cada pasta pode conter arquivos e outras pastas (subpastas).
Exemplo:
📁 Documentos
  ├── 📁 Trabalho
  ├── 📁 Pessoal
  └── 📁 Estudos
📄 Arquivos
São unidades de informação que contêm dados: textos, imagens, músicas, vídeos, planilhas. Cada arquivo tem um nome e uma extensão.
Exemplos:
📄 relatorio.docx (Word)
📄 planilha.xlsx (Excel)
📄 foto.jpg (Imagem)
📄 musica.mp3 (Áudio)
🧠 Dica: Organize seus arquivos em pastas com nomes claros e objetivos. Isso facilita encontrar o que precisa rapidamente.
07 GERENCIANDO PASTAS E ARQUIVOS
1
Criar
Clique com botão direito → Novo → Pasta. Digite o nome e pressione Enter
2
Renomear
Clique com botão direito → Renomear. Digite o novo nome e pressione Enter
3
Mover
Arraste com o mouse ou use Ctrl+X (recortar) + Ctrl+V (colar) na pasta de destino
4
Excluir
Clique com botão direito → Excluir ou pressione Delete. Vai para a Lixeira
⌨️ Atalhos úteis: F2 = Renomear · Delete = Excluir · Ctrl+C = Copiar · Ctrl+X = Recortar · Ctrl+V = Colar
08 LIXEIRA: APAGAR E RESTAURAR
🗑️ Apagar um Arquivo
1. Selecione o arquivo ou pasta
2. Clique com botão direito → Excluir
3. Confirme a exclusão
4. O item vai para a Lixeira
5. O arquivo não foi apagado definitivamente
♻️ Restaurar da Lixeira
1. Abra a Lixeira (ícone na área de trabalho)
2. Selecione o arquivo
3. Clique com botão direito → Restaurar
4. O arquivo volta para a pasta original
5. Pronto! Arquivo recuperado
⚠️ Atenção: Para apagar definitivamente, abra a Lixeira e use Esvaziar Lixeira. Depois disso, o arquivo não poderá mais ser recuperado pelos métodos comuns.
09 ATIVIDADES PRÁTICAS
1

  └── 📁 Estudos

2
Renomear e Organizar
Crie 3 arquivos de texto em "Trabalho". Renomeie para: relatorio.txt, planilha.txt, apresentacao.txt. Mova um deles para a pasta "Pessoal".
⏱️ Tempo: 40 min
3
Excluir e Restaurar
Exclua o arquivo "apresentacao.txt". Abra a Lixeira e verifique que ele está lá. Restaure o arquivo e confirme que voltou para a pasta "Trabalho".
⏱️ Tempo: 40 min
📌 Orientação ao professor: Verifique se os alunos compreenderam a hierarquia de pastas. Reforce que a Lixeira é uma área temporária e que "Esvaziar Lixeira" é uma ação definitiva. Auxilie individualmente quem tiver dificuldade com o mouse ou teclado.
