02 O QUE É INFORMÁTICA? — DEFINIÇÃO
Informação + Automática = Informática
É a ciência que estuda o tratamento automático da informação por meio de computadores e sistemas digitais. Envolve armazenar, processar e transmitir dados de forma rápida e precisa.
💡 Por que é importante?
A informática está presente em todas as áreas: saúde, educação, comércio, indústria e na vida pessoal. É uma competência essencial para o mercado de trabalho.
📝 Exemplo prático: Ao fazer um PIX pelo celular, a informática processa a transação, comunica os bancos e registra a operação — tudo em segundos.

04 HARDWARE vs SOFTWARE
🔧 Hardware
É a parte física do computador — tudo que pode ser tocado e visto.
Exemplos:
Monitor, teclado, mouse, gabinete, placa-mãe, processador, memória RAM, HD/SSD, fonte
💾 Software
É a parte lógica — os programas e instruções que fazem o hardware funcionar.
Exemplos:
Windows, Google Chrome, Google Docs, WhatsApp, jogos
Analogia: Hardware = corpo humano (ossos, órgãos) · Software = mente (pensamentos, instruções)
🖥️ Monitor — Hardware 🪟 Windows — Software ⌨️ Teclado — Hardware 🌐 Chrome — Software
🧠 Regra prática: Se você pode tocar, é hardware. Se você pode usar mas não tocar, é software.
05 COMPONENTES DO COMPUTADOR
🔲
Gabinete
Abriga placa-mãe, processador, memória, HD/SSD e fonte
🖥️
Monitor
Exibe imagens. Conecta via VGA, HDMI ou DisplayPort
⌨️
Teclado
Digita letras, números e comandos. USB ou Bluetooth
🖱️
Mouse
Move o cursor. Esquerdo: abrir. Direito: menu. Scroll: rolar
🔌
Estabilizador
Mantém tensão estável. Protege contra picos e quedas
🔀
Filtro de Linha
Protege contra surtos, sem estabilizar a tensão
06 PERIFÉRICOS DE ENTRADA E SAÍDA
⬅️ Entrada
Enviam dados do usuário para o computador.
⌨️ Teclado 🖱️ Mouse 🎤 Microfone 📷 Webcam 📠 Scanner
➡️ Saída
Recebem dados do computador para o usuário.
🖥️ Monitor 🖨️ Impressora 🔊 Som 🎧 Fone
🧠 Dica: Alguns dispositivos são mistos (entrada e saída), como o touchscreen (tela sensível ao toque) e o headset (fone com microfone).
07 LIGAR E DESLIGAR CORRETAMENTE
✅ PARA LIGAR
1. Ligue o estabilizador ou filtro de linha
2. Ligue o monitor (botão power)
3. Ligue o gabinete (botão power)
4. Aguarde o Windows carregar
5. Pronto! Computador disponível para uso
⛔ PARA DESLIGAR
1. Feche todos os programas abertos
2. Clique no botão Iniciar
3. Clique em Desligar
4. Aguarde desligar completamente
5. Desligue o estabilizador
⚠️ Atenção: Nunca desligue o computador diretamente no botão do gabinete ou no estabilizador. Isso pode corromper arquivos e danificar o sistema. O desligamento correto preserva a integridade dos dados.
💡 E se o computador travar? Mantenha pressionado o botão power por 5 a 10 segundos. Use apenas como último recurso.
