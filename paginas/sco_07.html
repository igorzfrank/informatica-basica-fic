02 LISTAS COM MARCADORES E NUMERAÇÃO
🔵 Lista com Marcadores
Para que serve: organizar itens que não têm ordem específica (ex: lista de compras, hobbies, características).
Como criar:
1. Selecione o texto
2. Clique no ícone • Lista com marcadores
3. Cada linha vira um item da lista
🔢 Lista Numerada
Para que serve: organizar itens em sequência lógica (ex: passos de uma receita, etapas de um processo).
Como criar:
1. Selecione o texto
2. Clique no ícone 1️⃣ Lista numerada
3. Os itens são numerados automaticamente
⌨️ Atalhos: Ctrl + Shift + 8 = Marcadores · Ctrl + Shift + 7 = Numeração

04 CORRIGIR ERROS (VERIFICAÇÃO ORTOGRÁFICA)
🔍 Como funciona
• O Google Docs sublinha em vermelho palavras com erro de grafia
• Palavras corretas não têm destaque
• O corretor identifica erros de digitação, acentuação e concordância
✏️ Como corrigir
1. Clique com botão direito na palavra sublinhada
2. Veja as sugestões de correção
3. Clique na opção correta
4. A palavra é corrigida automaticamente
💡 Dica: O corretor também funciona para inglês e outros idiomas. Configure o idioma em Arquivo → Idioma.

06 COMPARTILHAR DOCUMENTO (PERMISSÃO DE LEITURA)
🔗 Por que compartilhar?
Compartilhar permite que outras pessoas vejam seu documento sem precisar estar no mesmo computador. É útil para trabalhos em grupo, envio de tarefas ao professor e colaboração em tempo real.
📋 Passo a passo
1. Clique no botão "Compartilhar" no canto superior direito
2. Digite o e-mail da pessoa
3. No menu suspenso, escolha "Leitor"
4. Clique em "Enviar"
5. A pessoa recebe um e-mail com o link
👁️ Permissões: Leitor = só pode ver · Comentador = pode comentar · Editor = pode editar
